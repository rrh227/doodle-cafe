# Apply Cafe Visual Theme to UI

## Objective
Transform the functional UI into something that feels like a cozy cafe. Buttons look like chalkboard signs, the canvas looks like a napkin, meters look hand-drawn.

## Requirements
- Canvas frame: styled as a napkin or sketchpad (subtle paper texture via CSS, torn edges or tape corners)
- Tool palette: styled as a row of colored pencils/markers
- Serve button: large, styled as a cafe bell or "order up" button
- HUD: score on a chalkboard-style element, reputation as drawn stars
- Speech bubbles: hand-drawn style border (wobbly/organic edges via SVG or border-image)
- Background: subtle cafe counter pattern or simple warm gradient
- Title screen: cafe signage style with the game name
- Game over screen: "Closed" sign aesthetic
- All UI elements use the hand-drawn font (Patrick Hand, Caveat, or similar)
- Consistent use of the defined color palette throughout

## Acceptance Criteria
- [ ] All UI elements feel cohesive with the cafe theme
- [ ] Canvas area looks like a drawing surface (napkin/sketchpad)
- [ ] Buttons have themed styling (not default browser buttons)
- [ ] Font is consistent and fits the hand-drawn aesthetic
- [ ] Color palette is warm and inviting (cream, brown, pastels)
- [ ] Title screen sets the cafe mood immediately
- [ ] UI is still fully readable and accessible (contrast ratios acceptable)
